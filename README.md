# Yamada Studio Landing Page

## Descrição
Landing page responsiva e minimalista para trabalhos em corte e gravação a laser de diodo, inspirada na temática oriental, com design elegante e imagens geradas por IA.

## Como Usar

1. **Adicione suas imagens geradas por IA** na pasta `images/` (sugestões de nomes: `tattoo-oriental-1.jpg`, etc).
2. Edite os links de WhatsApp e Instagram no arquivo `index.html` para os corretos do seu estúdio.
3. Abra o `index.html` no navegador.

## Estrutura

- `index.html` — Página principal.
- `style.css` — Estilos.
- `script.js` — Funcionalidades JS básicas.
- `images/` — Coloque aqui suas imagens de alta qualidade geradas por IA.

## Requisitos Atendidos

- Design responsivo e minimalista.
- Layout e fontes elegantes.
- Fundos e imagens orientais.
- Botões de WhatsApp e Instagram.
- Opção melhorada para mobile.
- Acessibilidade (uso de ARIA-labels, contraste de cores).
- Desempenho otimizado (lazy loading de imagens).
- Segurança (sem coleta de dados pessoais).

## Sugestão de Prompts para Geração de Imagens IA

- "Tatuagem oriental tradicional, dragão vermelho e preto, fundo minimalista, alta definição"
- "Cortes de gravação a laser de diodo com estética japonesa, fundo preto e dourado, estilo sofisticado"
